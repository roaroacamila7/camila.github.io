HABILIDADES

Creatividad + código

Creo que una buena web necesita de las dos cosas. Aquí tienes las herramientas con las que trabajo día a día.

🎨

Diseño

La parte visual y estratégica. Donde todo empieza.

  • UI Design Interfaces limpias, modernas y con personalidad
  • Diseño responsive Adaptado a móvil, tablet y desktop sin perder calidad
  • Jerarquía visual El orden correcto para guiar la mirada del usuario
  • Composición Equilibrio, espacio en blanco y ritmo visual
  • Experiencia de usuario Flujos intuitivos que convierten visitantes en clientes
💻

Desarrollo

La parte técnica. Donde el diseño cobra vida.

  • HTML Semántico, accesible y bien estructurado
  • CSS Moderno, organizado y sin frameworks innecesarios
  • Responsive Design Mobile-first, breakpoints pensados, fluidos
  • Git Control de versiones, ramas, commits limpios
🌐

Plataformas

Cuando el proyecto lo pide, también trabajo sin código.

  • Wix Studio Diseño avanzado, CMS, animaciones, responsive total
  • Squarespace Templates personalizados, blog, e-commerce simple

Lo que no hago (y está bien)

  • Backend complejo (Node, PHP, Python, bases de datos)
  • Apps móviles nativas
  • Sistemas complejos a medida (ERP, CRM, marketplaces)
  • Mantenimiento de código legacy ajeno sin documentar

Si tu proyecto necesita eso, te ayudo a encontrar a la persona indicada.
